Set up an on-call backup bench of ~5 caregivers on a retainer/standby fee so that no patient is ever left unattended if a primary caregiver is unavailable. This directly mitigates the supply-shortfall risk.

- **Timeline:** Month 2 onward
- **Est. cost:** ~NPR 50,000 (retainer / standby fees)
- **Depends on:** recruit-vet-caregivers.
- **Hand off to:** Care Coordinator — the bench is theirs to draw on for escalations.
- **Done when:** 5 vetted, trained backup carers are on standby and the Coordinator knows how to call them in.
